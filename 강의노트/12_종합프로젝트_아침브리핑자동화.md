    ▼

    │
    ▼

  │   크롬 종료 → 주소로 열기 (R3) → 크롬 화면 확인 (R4) │

## 3️⃣ **구현: 단계별 코드**

전체 코드는 [`예제코드/project_briefing.py`](../예제코드/project_briefing.py)에 있습니다. 중요한 부분을 나누어 살펴봅니다.

### **설정값 모아 두기 (R5)**

```python
BROWSER = "com.android.chrome"
PAGES = [                                     # (이름, 주소) - 원하는 페이지로 바꾸세요
    ("날씨", "https://www.google.com/search?q=seoul+weather"),
    ("뉴스", "https://news.google.com/?hl=ko&gl=KR&ceid=KR:ko"),
    ("환율", "https://www.google.com/search?q=usd+krw"),
]
CLOSE_FIRST = ["com.google.android.youtube"]  # 화면을 덮을 수 있는 앱 (PIP 등)
OUT_DIR = "runs"
```

바뀔 수 있는 값은 코드 맨 위에 모읍니다. 보고 싶은 페이지를 추가하려면 `PAGES`에 한 줄만 더 쓰면 됩니다. 뉴스 주소처럼 `&`가 들어간 주소도 `adb_helper.open_url`이 작은따옴표로 감싸 주므로 그대로 써도 됩니다 (7장).

### **R1: 깨우기와 잠금 확인**

```python
def wake_and_unlock_check():
    key("KEYCODE_WAKEUP")
    time.sleep(0.5)
    locked = "mDreamingLockscreen=true" in shell("dumpsys window | grep mDreamingLockscreen")
    if locked:
        raise AdbError("폰이 잠겨 있습니다. 잠금을 풀어 두거나 충전 중 화면 켜짐 유지를 켜세요")
```

잠금 화면을 매크로로 풀지 않습니다. 비밀번호를 스크립트에 적는 것은 위험하기 때문입니다 (11장).

### **R3~R4: 열고, 확인하기**

```python
def open_page(url):
    stop(BROWSER)                       # 크롬 완전 종료 → 매번 같은 상태
    time.sleep(1)
    open_url(url, BROWSER)              # 주소로 바로 열기
    for _ in range(20):                 # 0.5초 x 20 = 최대 10초
        pkg, _ = current_app()
        if pkg == BROWSER:
            return True                 # 크롬 화면이 앞에 떴다!
        time.sleep(0.5)
    return False
```

웹페이지 안의 글자는 사이트마다 다르고 XML에 잡히지 않을 수도 있으므로, **글자 대신 지금 화면의 패키지명으로 "제대로 열렸는지"를 확인**합니다.

### **R6: 날짜별 폴더와 실행 기록**

```python
day_dir = os.path.join(OUT_DIR, datetime.date.today().isoformat())   # runs/2026-10-09
os.makedirs(day_dir, exist_ok=True)

def record(page, result, seconds, memo):
    path = os.path.join(OUT_DIR, "history.csv")
    new = not os.path.exists(path)
    with open(path, "a", newline="", encoding="utf-8-sig") as f:
        w = csv.writer(f)
        if new:
            w.writerow(["시각", "페이지", "결과", "걸린 시간(초)", "메모"])
        w.writerow([datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S"),
                    page, result, f"{seconds:.1f}", memo])
```

`encoding="utf-8-sig"`를 쓰면 엑셀에서 열어도 한글이 깨지지 않습니다.

### **실패해도 계속 진행: 페이지마다 try / except**

```python
for i, (name, url) in enumerate(PAGES, 1):
    try:
        if not open_page(url):
            raise AdbError("브라우저 화면이 뜨지 않았습니다")
        time.sleep(4)                   # 페이지 내용이 그려질 시간
        result = "성공"
    except AdbError as e:
        result, memo = "실패", str(e)

    screenshot(os.path.join(day_dir, f"{i:02d}_{name}.png"))   # 성공이든 실패든 실행
    record(name, result, time.time() - start, memo)
```

`try/except`가 반복문 **안**에 있으므로, "뉴스"가 실패해도 "환율"은 그대로 진행됩니다.

## 5️⃣ **자동 실행 등록**

9장에서 배운 cron으로 평일 아침 7시 30분에 실행되도록 등록합니다.

```bash
which python3      # 예: /opt/homebrew/bin/python3
crontab -e
```

```bash
30 7 * * 1-5 cd ~/Desktop/mobile-macro-guide/예제코드 && PATH=/opt/homebrew/bin:$PATH python3 project_briefing.py >> cron.log 2>&1
```

| 부분 | 의미 |
| --- | --- |
| `30 7 * * 1-5` | 월~금 7시 30분 |
| `cd .../예제코드` | `adb_helper.py`가 있는 폴더로 이동 |
| `PATH=/opt/homebrew/bin:$PATH` | cron에서도 `adb`, `python3`를 찾도록 |
| `>> cron.log 2>&1` | 출력과 오류를 로그로 |

### **등록 전 점검표**

- [ ] 터미널에서 `python3 project_briefing.py`가 성공한다
- [ ] 폰이 충전 중이고 `충전 중 화면 켜짐 유지`가 켜져 있다
- [ ] 폰 화면 잠금이 없거나, 실행 시각에 잠금이 풀려 있다
- [ ] Mac이 그 시각에 잠자기 상태가 아니다 (또는 launchd 사용)
- [ ] 다음 날 `runs/history.csv`와 캡처로 결과를 확인한다

좋은 매크로는 요구사항 정리 → 실행 흐름 설계 → 단계별 구현 → 실패 대비 → 기록 → 자동 실행 등록의 순서로 만듭니다.

### **과제 2: 주간 리포트**

`runs/history.csv`를 읽어 최근 일주일간 페이지별 성공률과 평균 걸린 시간을 출력하는 프로그램을 작성하세요.

```python
# 힌트
import csv
from collections import defaultdict

rows = list(csv.DictReader(open("runs/history.csv", encoding="utf-8-sig")))
by_page = defaultdict(list)
for r in rows:
    by_page[r["페이지"]].append(r)

for page, items in by_page.items():
    ok = sum(r["결과"] == "성공" for r in items)
    avg = sum(float(r["걸린 시간(초)"]) for r in items) / len(items)
    print(f"{page}: 성공률 {ok / len(items) * 100:.0f}%, 평균 {avg:.1f}초")
```

축하합니다! 1장에서 `adb devices`로 연결을 확인하던 것에서 시작해, 이제 정해진 시각에 스스로 실행되고, 실패하면 이유를 기록하는 매크로를 완성했습니다.

앞으로 새로운 매크로를 만들 때는 이 순서를 기억하세요.

```
주소가 있나? → 글자로 찾을 수 있나? → 위치가 고정인가? → 이미지로 찾을까?
      ↓
요구사항 → 흐름 설계 → 구현 → 실패 대비 → 기록 → 자동 실행
      ↓
약관과 보안 확인
```
