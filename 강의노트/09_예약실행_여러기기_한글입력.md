## 2️⃣ **Python으로 정각 맞추기**

### **기본: 목표 시각까지 기다리기**

```python
import datetime, time

target = datetime.datetime.now().replace(hour=10, minute=0, second=0, microsecond=0)

while datetime.datetime.now() < target:
    time.sleep(0.1)

print("10시 정각! 실행합니다")
```

`replace`는 현재 날짜는 그대로 두고 시·분·초만 바꾼 새 시각을 만듭니다.

### **정확도 높이기: 미리 준비, 정각에 한 방**

앱을 열고 페이지를 띄우는 데 몇 초가 걸립니다. 정각에 앱을 열기 시작하면 이미 늦습니다.

```
❌ 정각에 모든 걸 시작                    ✅ 미리 준비, 정각엔 버튼만

 10:00:00  앱 실행                       09:59:00  앱 실행, 페이지 열기 (준비)
 10:00:04  페이지 열림                    09:59:05  준비 완료, 대기
 10:00:06  버튼 탭  ← 6초 늦음             10:00:00  버튼 탭  ← 정각
```

### **예제 1: scheduled_run.py**

전체 코드는 [`예제코드/scheduled_run.py`](../예제코드/scheduled_run.py)에 있습니다.

```python
PREPARE_SEC = 60

def prepare():                       # 정각 60초 전
    key("KEYCODE_WAKEUP")
    stop(PACKAGE)
    open_url(URL, PACKAGE)
    time.sleep(5)

def fire():                          # 정각
    tap_text("받기", timeout=5)

def wait_until(target):
    while True:
        left = (target - datetime.datetime.now()).total_seconds()
        if left <= 0:
            return
        # 많이 남았으면 길게 자고, 1초 안쪽은 0.01초 간격으로 촘촘히 확인
        time.sleep(min(left - 0.5, 30) if left > 1 else 0.01)
```

```bash
cd 예제코드
python3 scheduled_run.py 10:00:00          # 실제 예약
python3 scheduled_run.py 10:00:00 --now    # 1분 뒤로 당겨서 테스트
```

```
목표 시각: 10:00:00
[09:59:00] 준비 시작
[10:00:00.004210] 실행!
완료
```

## 3️⃣ **cron: 매일·매주 자동 실행**

cron은 Mac(과 Linux)에 들어 있는 예약 실행기입니다.

```bash
crontab -e      # 예약 목록 편집 (vi 편집기가 열림: i로 입력, ESC → :wq로 저장)
crontab -l      # 예약 목록 보기
```

### **cron 시간 형식**

```
┌───────── 분 (0-59)
│ ┌─────── 시 (0-23)
│ │ ┌───── 일 (1-31)
│ │ │ ┌─── 월 (1-12)
│ │ │ │ ┌─ 요일 (0-6, 0=일요일 … 3=수요일 … 6=토요일)
│ │ │ │ │
* * * * *  실행할 명령
```

| 예 | 의미 |
| --- | --- |
| `0 9 * * *` | 매일 9시 0분 |
| `58 9 * * 3` | 매주 수요일 9시 58분 |
| `*/30 * * * *` | 30분마다 |
| `0 9 * * 1-5` | 평일 9시 |
| `0 0 1 * *` | 매월 1일 자정 |

### **예제 2: 매주 수요일 9시 58분에 고재팬 매크로 실행**

```bash
58 9 * * 3 cd ~/Desktop/mobile-macro-guide/예제코드 && /opt/homebrew/bin/python3 macro_v2.py >> cron.log 2>&1
```

| 부분 | 의미 |
| --- | --- |
| `cd ~/Desktop/.../예제코드` | 예제 코드 폴더로 이동 (adb_helper를 불러오기 위해) |
| `/opt/homebrew/bin/python3` | **전체 경로**로 실행 (cron은 PATH가 짧음) |
| `>> cron.log 2>&1` | 출력과 오류를 모두 로그 파일에 이어 쓰기 |

> ⚠️ cron 안에서는 `adb`, `python3`를 못 찾는 경우가 많습니다. `which adb`, `which python3`로 전체 경로를 확인해 쓰세요. `adb_helper.py`가 `adb`를 찾지 못하면 맨 위에 `os.environ["PATH"] += ":/opt/homebrew/bin"`을 추가합니다.

> ⚠️ 최신 macOS에서는 cron이 데스크톱·문서 폴더에 접근하려면 `시스템 설정 → 개인정보 보호 및 보안 → 전체 디스크 접근 권한`에 `/usr/sbin/cron`을 추가해야 할 수 있습니다.

## 4️⃣ **launchd: Mac 공식 예약 실행**

launchd는 Mac이 잠자기 중이라 놓친 예약을 깨어난 뒤 실행해 줍니다. 설정 파일(plist)을 만들어 등록합니다.

### **예제 3: 매주 수요일 9시 58분 (launchd)**

`~/Library/LaunchAgents/com.me.gojapan.plist` 파일을 만듭니다.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.me.gojapan</string>

    <key>WorkingDirectory</key>
    <string>/Users/사용자이름/Desktop/mobile-macro-guide/예제코드</string>

    <key>ProgramArguments</key>
    <array>
        <string>/opt/homebrew/bin/python3</string>
        <string>macro_v2.py</string>
    </array>

    <key>EnvironmentVariables</key>
    <dict>
        <key>PATH</key>
        <string>/opt/homebrew/bin:/usr/bin:/bin</string>
    </dict>

    <key>StartCalendarInterval</key>
    <dict>
        <key>Weekday</key><integer>3</integer>   <!-- 수요일 -->
        <key>Hour</key><integer>9</integer>
        <key>Minute</key><integer>58</integer>
    </dict>

    <key>StandardOutPath</key>
    <string>/tmp/gojapan.log</string>
    <key>StandardErrorPath</key>
    <string>/tmp/gojapan.err</string>
</dict>
</plist>
```

```bash
# 등록
launchctl load ~/Library/LaunchAgents/com.me.gojapan.plist

# 지금 바로 한 번 실행해서 테스트
launchctl start com.me.gojapan

# 해제
launchctl unload ~/Library/LaunchAgents/com.me.gojapan.plist
```

`사용자이름`은 터미널에서 `whoami`로 확인한 이름으로 바꾸세요.

### **Mac이 잠들지 않게 하기**


## 5️⃣ **여러 기기 다루기**

### **시리얼로 기기 지정하기**

```bash
adb devices
# SERIAL	device
# 192.168.0.15:41234	device

adb -s SERIAL shell input tap 540 1200          # 첫 번째 폰만
adb -s 192.168.0.15:41234 shell input tap 540 1200   # 두 번째 폰만
```

기기가 2대 이상인데 `-s`를 빼면 `more than one device/emulator` 오류가 납니다.

### **예제 4: 모든 폰에서 동시에 같은 매크로 실행**

`adb_helper`의 `SERIAL` 변수는 하나뿐이므로, 여러 기기를 동시에 쓸 때는 시리얼을 인자로 받는 함수를 만들고 스레드로 나눕니다.

```python
import subprocess
import threading
import time

def adb_s(serial, *args):
    return subprocess.run(["adb", "-s", serial, *map(str, args)], capture_output=True).stdout

def job(serial):
    adb_s(serial, "shell", "am", "force-stop", "com.android.chrome")
    adb_s(serial, "shell", "am", "start", "-a", "android.intent.action.VIEW",
          "-d", "https://www.google.com", "com.android.chrome")
    time.sleep(3)
    with open(f"shot_{serial.replace(':', '_')}.png", "wb") as f:
        f.write(adb_s(serial, "exec-out", "screencap", "-p"))
    print(f"✅ {serial} 완료")

out = subprocess.run(["adb", "devices"], capture_output=True, text=True).stdout
serials = [l.split("\t")[0] for l in out.splitlines()[1:] if l.endswith("\tdevice")]

threads = [threading.Thread(target=job, args=(s,)) for s in serials]
for t in threads:
    t.start()          # 모두 동시에 시작
for t in threads:
    t.join()           # 모두 끝날 때까지 기다림
print(f"{len(serials)}대 모두 완료")
```

```
✅ SERIAL 완료
✅ 192.168.0.15:41234 완료
2대 모두 완료
```

```
스레드로 동시 실행

  메인 ──┬── 스레드 1: 폰 A  [종료 → 열기 → 캡처]
         ├── 스레드 2: 폰 B  [종료 → 열기 → 캡처]   ← 동시에 진행
         └── join: 모두 끝날 때까지 대기 ──► "2대 모두 완료"
```

## 6️⃣ **한글 입력: ADBKeyboard**

2장에서 본 것처럼 `input text`는 한글을 입력하지 못합니다. **ADBKeyboard**는 adb에서 보낸 글자를 그대로 입력해 주는 키보드 앱입니다.

### **설치와 설정**

1. [ADBKeyBoard 저장소](https://github.com/senzhk/ADBKeyBoard)의 Releases에서 `ADBKeyboard.apk`를 받습니다.
2. 설치하고 키보드를 바꿉니다.

```bash
adb install ADBKeyboard.apk

# 현재 키보드 확인 (나중에 되돌릴 때 필요)
adb shell settings get secure default_input_method
# com.samsung.android.honeyboard/.service.HoneyBoardService

# ADBKeyboard 켜고 기본 키보드로 지정
adb shell ime enable com.android.adbkeyboard/.AdbIME
adb shell ime set com.android.adbkeyboard/.AdbIME
```

### **예제 5: 한글 검색하기**

```bash
adb shell input tap 720 300                                   # 입력창 터치
adb shell am broadcast -a ADB_INPUT_TEXT --es msg '오사카 맛집'   # 한글 입력
adb shell input keyevent KEYCODE_ENTER
```

Python에서는 이렇게 씁니다.

```python
def text_ko(s):
    shell(f"am broadcast -a ADB_INPUT_TEXT --es msg '{s}'")

text_ko("오사카 맛집")
```

### **원래 키보드로 되돌리기**

ADBKeyboard는 화면에 자판이 나오지 않으므로, 매크로를 다 쓰면 원래 키보드로 돌려놓습니다.

```bash
adb shell ime set com.samsung.android.honeyboard/.service.HoneyBoardService
```

앞에서 확인한 원래 키보드 값을 넣으세요. 10장의 uiautomator2를 쓰면 키보드를 바꾸지 않고도 한글을 입력할 수 있습니다.

## 📝 **핵심 개념 정리**

정각 승부가 필요한 매크로는 Python에서 목표 시각까지 기다리되, 앱 열기 같은 준비는 미리 해 두고 정각에는 버튼만 누릅니다. 마지막 1초는 짧은 간격으로 확인해야 정확합니다.

매일·매주 반복은 cron(`분 시 일 월 요일 명령`)이나 launchd(plist)로 예약합니다. 예약 실행 환경은 PATH가 짧으므로 `python3`, `adb`의 전체 경로를 쓰고, 출력은 로그 파일로 남깁니다.

기기가 여러 대면 `adb -s 시리얼`로 지정하고, `threading`으로 동시에 실행할 수 있습니다. 한글은 ADBKeyboard를 설치해 `am broadcast -a ADB_INPUT_TEXT --es msg '한글'`로 입력하고, 끝나면 원래 키보드로 되돌립니다.

## 🔑 **퀴즈 정답 및 해설**

**1번 정답: 2**
cron은 `분 시 일 월 요일` 순서입니다. 58분, 9시, 매일, 매월, 수요일(3)입니다.

**2번 정답: 3**
`-s`(serial) 뒤에 `adb devices`에 나온 시리얼을 씁니다. 무선 연결은 `IP:포트`가 시리얼입니다.

**3번 정답: 2**
cron은 아주 짧은 PATH로 명령을 실행하므로 Homebrew로 설치한 adb(`/opt/homebrew/bin`)를 찾지 못합니다. 전체 경로를 쓰거나 PATH를 지정해야 합니다.

**4번 정답: 2**
앱을 열고 페이지가 뜨기까지 몇 초가 걸리므로 미리 준비해야 합니다. 3번처럼 계속 누르는 것은 봇으로 감지되거나 약관 위반이 될 수 있습니다.

**5번 정답: 2**
ADBKeyboard는 adb가 보낸 글자만 입력하는 키보드라서 자판이 보이지 않습니다. 매크로가 끝나면 원래 키보드로 바꿔야 평소처럼 폰을 쓸 수 있습니다.
